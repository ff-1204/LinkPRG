# LinkPRG

끝까지 해낸 사람에게 종소리가 들리는 세계. 글과 대화방으로 하는 혼자용 RPG입니다. 게임 안에서의 이름은 "띠링"입니다.

**바로 하기: https://ff-1204.github.io/LinkPRG/**

- 한 번 누르면 한 번 합니다. 100번은 손으로 100번 누릅니다.
- 고생한 만큼 돌아옵니다. 남들이 그만둔 뒤에도 계속하면 숨어 있던 것이 답합니다.
- 설치가 없습니다. 브라우저에서 바로 열립니다. 저장은 이 기기 안에 남습니다.

## 들어 있는 것

- 주사위로 정하는 시작 스탯, 출신 여섯
- 숙련도, 직업과 전직, 전투 태세 넷(버티기·맞받아치기·피하기·모으기)
- 제작과 강화, 장비 옵션, 조각, 요리
- 사람들과의 친밀도, 의뢰와 퀘스트, 칭호, 길드
- 시간과 피로, 포만감, 야영과 여인숙
- 던전, 이름난 개체, 가상 유저들의 세계 공지와 랭킹, 경매장
- 글자 크기·고대비·화면읽기 지원, 누르기 돕기, 휴대폰 화면

## 내 컴퓨터에서 열기

```bash
node tools/serve.js
```

그다음 브라우저에서 `http://localhost:5180`을 엽니다. Node 20 이상이 필요하고 설치할 것은 없습니다. 빌드가 없어서 폴더째 올리면 그대로 돕니다.

## 테스트

```bash
node --test tests/
```
