구글 드라이브 저장 시안

구글로 로그인하면 저장 칸 셋이 내 구글 드라이브에도 남습니다. 다른 컴퓨터나 휴대폰에서 같은 구글 계정으로 로그인하면 이어서 할 수 있습니다. 로그인하지 않아도 지금처럼 이 기기 안에서 그대로 됩니다.

1. 저장과 설정 창

저장과 설정닫기

3. 언제 올리나

저절로 올린다추천이 기기에 저장될 때마다 몇 초 모아서 드라이브에도 올린다. 잊어버릴 일이 없다.
손으로 올린다"지금 올리기"를 누를 때만. 드라이브와 이 기기가 어긋나기 쉽다.
되감는 저장은 만들지 않습니다(지키는 것 3번). 드라이브에도 칸마다 가장 나중 상태 하나만 둡니다. 옛 판을 골라 받는 길은 없습니다. 이 기기와 드라이브 가운데 저장 횟수(판 번호)가 더 큰 쪽을 씁니다. 그래서 "죽기 전 판을 드라이브에서 다시 받기" 같은 길은 열리지 않습니다.

4. 만드는 방식

무엇어떻게
로그인구글이 주는 로그인 창(Google Identity Services). 서버 없이 브라우저에서만 된다
드라이브에서 쓰는 곳앱 전용 숨은 폴더(appDataFolder). 사용자의 다른 파일은 보지도 건드리지도 못한다
필요한 값OAuth 클라이언트 ID 하나(공개해도 되는 값). 비밀값은 쓰지 않는다
비용없음
로그인 정보접근 토큰은 브라우저 안에만, 한 시간쯤 쓰고 버린다. 저장소에 넣지 않는다
바깥 코드구글 로그인 스크립트 하나를 불러온다(accounts.google.com). 로그인을 누를 때만 불러온다. 지금까지 지킨 "의존성을 넣지 않는다"의 예외가 된다

5. 사용자가 구글 콘솔에서 할 일 (한 단계씩 같이 갑니다)

  1. 구글 클라우드 콘솔에서 프로젝트 하나 만들기
  2. Google Drive API 켜기
  3. OAuth 동의 화면 만들기(외부, 테스트 상태로 두고 내 계정을 테스트 사용자로)
  4. OAuth 클라이언트 ID 만들기(웹 애플리케이션, 허용 주소: https://ff-1204.github.io 와 http://localhost:5180)
  5. 클라이언트 ID만 복사해서 알려 주기(JSON 내려받기나 시크릿은 필요 없음)

테스트 상태에서는 테스트 사용자로 넣은 계정만 로그인됩니다. 다른 사람도 쓰게 하려면 동의 화면을 "프로덕션"으로 게시해야 하는데, 이건 공개 결정이라 직접 하셔야 합니다.

6. 정해 주실 것

  1. 화면(1·2번)이 이대로 괜찮은지
  2. 언제 올리나: 저절로 / 손으로
  3. 구글 로그인 스크립트를 불러오는 것(의존성 규칙의 예외)이 괜찮은지
