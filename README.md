# LinkPRG

끝까지 해낸 사람에게 종소리가 들리는 세계. 글과 대화방으로 하는 혼자용 RPG입니다.

**바로 하기: https://ff-1204.github.io/LinkPRG/**

- 한 번 누르면 한 번 합니다. 100번은 손으로 100번 누릅니다.
- 고생한 만큼 돌아옵니다. 남들이 그만둔 뒤에도 계속하면 숨어 있던 것이 답합니다.
- 설치가 없습니다. 브라우저에서 바로 열립니다. 저장은 이 기기 안에 남고, 원하면 구글 드라이브에도 둘 수 있습니다.

## 들어 있는 것

- 레벨 1부터 100까지 이어지는 지역 열 곳. 지역마다 그곳에서만 통하는 규칙이 하나씩 있습니다
- 3부 열세 장의 이야기. 장마다 푸는 길이 여럿이고, 어떻게 풀어 왔는지가 고를 수 있는 끝을 정합니다
- 주사위로 정하는 시작 스탯, 출신, 직업과 전직, 전투 태세 넷(버티기·맞받아치기·피하기·모으기)
- 숙련도, 제작 열 단계와 승급작, 강화, 장비 옵션, 조각, 요리
- 사람들과의 친밀도, 의뢰와 퀘스트, 히든 퀘스트, 칭호, 길드
- 동료와 용병. 뒤로 갈수록 음식, 성수, 용병을 갖춰야 합니다
- 가게, 공방과 견습, 상단. 내가 움직일 때만 돕니다. 꺼 두거나 쉬는 동안에는 쌓이지 않습니다
- 시간과 피로, 포만감, 야영과 여인숙, 보관함
- 던전, 이름난 개체, 가상 유저들의 세계 공지와 랭킹, 경매장
- 쓰러짐과 환생. 손에 익은 것(숙련도, 제작 레벨)은 다음 삶으로 가져갑니다
- 글자 크기·고대비·화면읽기 지원, 누르기 돕기, 휴대폰 화면

## 내 컴퓨터에서 열기

```bash
node tools/serve.js
```

그다음 브라우저에서 `http://localhost:5180`을 엽니다. Node 20 이상이 필요하고 설치할 것은 없습니다. 빌드가 없어서 폴더째 올리면 그대로 돕니다.

## 테스트

```bash
node --test tests/
```

## 알아 둘 것

- 시험판(v0.9.0)입니다. 레벨 21부터 100까지는 막 넣은 것이라 숫자와 글이 바뀔 수 있습니다.
- 저장은 브라우저 안에 있습니다. 브라우저 데이터를 지우면 사라지니 "파일로 내보내기"로 따로 간직해 두세요.
- "저장과 설정"에서 구글로 로그인하면 저장이 내 구글 드라이브의 앱 전용 숨은 폴더에도 남아 다른 기기에서 이어 할 수 있습니다. 게임은 그 폴더만 쓰고 다른 파일은 보지 못합니다. 자세한 것은 [개인정보처리방침](https://ff-1204.github.io/LinkPRG/privacy.html)에 있습니다.
- 옛 판에서 하던 저장은 새 판에서 그대로 이어집니다.
